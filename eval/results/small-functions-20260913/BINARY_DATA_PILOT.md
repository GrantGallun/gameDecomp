# Binary-data catalog pilot

`solver.binary_data` reads hash-pinned binary assembly, optionally verifies every emitted byte against a pinned ROM, and separates readonly initial bytes, mutable initial bytes, BSS, and MMIO. Literal directives are independently encoded; explicit symbolic words require an independently pinned symbol map to count as reconstructed. Numeric address-looking words are not automatically pointers. Labels bound emitted spans, not inferred C objects.

The checkpoint 13212 offline pilot processed 177 pinned assembly inputs against the 8,388,608-byte ROM in about 2 seconds. It recorded 1,567 regions: 194,524 file-backed bytes, 188,416 independently reconstructed bytes, 1,527 named address references, and 514,752 unbacked BSS bytes. File-backed storage includes 9,025 readonly bytes and 185,499 mutable initial bytes. There were no unparsed directives or output omissions. No independent symbol map was supplied, so 6,108 symbolic bytes remain extracted/ROM-verified rather than reconstructed. Typed-C-verified bytes remain zero. This is the named-data-assembly subset; unlisted ROM assets are outside the measured denominator.

Six motivating packets were nonempty and 1,097–2,493 characters: Fcutoff, Fdrums, Fendit, initRaceCameraChase, initRaceCameraPositionTransition, and getRaceCourseNextSurface. Incoming address references must match the actual hash-bound target entry before appearing in a packet. Adjacent references are table candidates, not proven dispatch sites or ABIs. Data relocations indicate reference relationships, not exclusive ownership.

The parser and artifacts are bound in `binary-data-pilot-receipt.json`. `binary-data-catalog.json` contains regions and provenance; `binary-data-packets.json` contains the selected packets. Reproduction: run `catalog_pilot.py` in WSL with repository PYTHONPATH; inputs are read-only and only this audit directory is written. `verify_candidate` compares supplied bytes against one ROM-verified emitted span and reports the first difference; it does not establish compilation/source lineage or promote C.

Validation at this point: 22 catalog tests pass; combined with dataflow and callback-ABI tests, 38 pass. Consumer admission tests in `test_data_memory.py` independently exercise ROM fallback and preserve errors in candidate-owned data; see parent release validation for its final composed result.
