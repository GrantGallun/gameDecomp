fresh Clang candidate line/column diagnostics and exact displayed-line checks.
It declines missing/stale excerpts, tab-expanded locations and overlapping or
excessive edits. It never changes public prototypes or relaxes warning policy.

  casts, gated by ELF32 big-endian MIPS o32. No guessed identifier conversions.

  RHS: existing arithmetic is preserved, not assumed to use byte units.

  signed conversion. Conflicting header signatures decline.
