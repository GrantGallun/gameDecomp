# RNG targeted swarm experiment

`__MusIntRandom` improved from **98.590 to 100% object-section exact** and passed
**256/256 saved differential cases**. The strict project frontend check passed.
The source is an experiment artifact, not integrated production source, and the
certificate does not claim a whole-ROM build.

The old residual had two independent causes: the staged floating-point return
created an unnecessary second quotient lifetime, and generated nested loop
scaffolding changed the prologue scheduling of two independent instructions.

Reusing the quotient local through both divisions, with no reassociation or
change of precision, raised the score to 99.231. Recovering an ordinary counted
loop fixed the remaining instruction order. A natural eight-iteration single
body loop also matches exactly: IDO performs the four-way unrolling itself.

The reusable operator is `solver/rng_alternatives.py`. It recognizes the staged
return generated by the earlier operator and emits bounded storage alternatives
plus a paired counted-loop recovery. Matching is scoped to the requested
function and ignores comments and literals. Recovery retains the counter-update
position and requires a positive divisible constant trip count, no counter use
in the body, and no early control transfer. Original body text is preserved.

The final operator reproduces exactness with its **second candidate**, recorded
in `../swarm-rng-v1/scores.json`. Six separately compiled loop experiments are
recorded in `../swarm-rng-loops/scores.json`; five were exact. The preferred
natural loop artifact is `__MusIntRandom.c` in this directory. `receipt.json`
contains its fresh compiler certificate and all 256 replay results (attempt
31950). Five operator safety/source-scope tests pass.

## Applicable compiler guidance

The workspace's `DECOMPILATION_LEARNINGS.md` sections “When to use these vs. the
permuter” and “IDO codegen: optimization level and control flow” recommend clean
source shapes to steer register allocation, production object verification of
permuter winners, and attention to source scheduling. We followed those rules:
all scoring used the production build wrapper and unchanged compiler recipe;
the final decision uses allocated sections and relocation expressions, not debug
collateral. The workspace's “unrolled-loops” guidance also suggested recovering
the natural loop rather than retaining four duplicated bodies, which reproduced
the exact object.
