The first 15 completed jobs added 99 durable attempts and preserved all 972 object-exact/integrated functions. During batch 2, inspection found the register-search adapter stores its probe attempts in a discarded in-memory DB and drops source-attribution/frontend evidence before calling the mutation stream. Stop at the batch boundary before the affected search budgets are spent.

An independent private regeneration of audioThreadMain reached ordinary frontend/object acceptance via a local integer type edit after 13 proposals. Current normal scheduling cannot derive that edit: zero register faults exclude register search, and local_rewrites owns another stream. Existing binary retry only redrafts/rescores. No private winning source will be imported.

Bounded implementation:

- Persist every register probe in the worker DB, including failures, with actual-parent lineage. Carry its full fresh evidence into mutation generation. Preserve acceptance gates and existing search budgets.
- Add eval.operand_repair as the existing measured deterministic greedy/restart stream, bounded to 72 proposals, receiving current compiler attribution and binary-only rodata evidence. Start from the incumbent, retain its best result, and log all attempts/parents.
- Schedule one versioned operand-repair visit on compiled, frontend-passing pending nodes with at most two structural faults. Do not reopen closed nodes or reset model budgets. A changed generator identity permits one new visit; changing the incumbent alone does not reset this visit.
- Test failure/logging/lineage/evidence wiring and motivating generation. Prove audio regeneration through normal controller execution in a private native campaign, then apply a scoped frozen amendment while paused and resume the deterministic queue.

Preserve scoped before-images under before-fix, modify main owners, and test an isolated native copied frozen package with explicit overlays. Do not commit or alter unrelated files.
