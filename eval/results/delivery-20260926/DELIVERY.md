## What is delivered in main

- `binary_type_facts` regenerates observations; `binary_type_identity` uses fixed D32; `binary_type_context` caches observations by ELF and extractor implementation and emits candidate declarations.
- `binary_type_draft` preprocesses a narrow public prelude, offers ordinary and valid-syntax drafts with bounded stride follow-up, and logs hashes of generating inputs. It never loads the experiment's winning sources, FIT records or reconstructed game headers.
- Normal intake scores clean roots alongside existing routes. Binary retries retain a superior usable incumbent; frontend rejection cannot defeat its valid C gate. Unchanged source-bound semantic receipts survive a retry. Placeholder descendants retain binary evidence and source derivation hashes.
- The scheduler versions retries by code and frozen ELF/SDK/m2c inputs; a missing-input revision cannot suppress a later input amendment. Exact and parked nodes remain closed.
- `fast_campaign --deterministic-only` retains the stored configuration, filters model profiles, refuses model work already in flight, and skips integration/runtime capture for that bounded process.

The fixed D32 policy was selected historically using FIT labels. Source-independent generation here is a provenance claim about current candidate inputs, not an unseen/generalization benchmark claim.
